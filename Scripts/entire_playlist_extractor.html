Learning Space Digital — Playlist Extractor v3

Open Learning Space Digital Playlists

Fixed: This version will NOT use Loading, View full playlist, or View full course as a playlist name. It reads the actual YouTube lockupMetadataViewModel.title.content together with its matching contentId.

How to run

  1. Open the live YouTube Playlists page.
  2. Press F12 → Console.
  3. Paste the script below.
  4. Press Enter.
  5. Wait while the page scrolls and loads more playlists.
  6. A CSV named learning-space-digital-playlists.csv will download.
